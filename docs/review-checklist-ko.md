# 다시듣기 v2 심사 체크리스트

[공개 작업 공간](https://replay-a11y-hybrid-2026.web.app/)을 데스크톱 Chrome에서 엽니다. 아래 절차는 한국어 UI에서 내장 영어 배송지 변경 샘플을 사용합니다. 기기 내 모델과 로컬 카드는 선택 사항입니다.

**확인 기준:** 굵은 글씨는 UI 레이블과 상태 문구입니다. 초점과 UI 상태를 확인하는 절차이며, 특정 문구가 반드시 낭독된다는 뜻은 아닙니다. 실제 스크린리더 발화는 별도로 확인해야 하며, 모바일 TalkBack 녹음은 아직 없습니다.

1. 기본 영어 화면에서 먼저 Tab으로 **한국어**에 이동해 Enter를 누릅니다. 초점은 같은 버튼에 남고 버튼 문구는 **English**로 바뀝니다.
2. **영어 합성 샘플 불러오기**를 Enter로 누릅니다. 초점이 이동한 **2. 수정 전후 비교**에서 `Button` → `Change delivery address, Button`을 확인하고 **카드에 들어갈 정확한 문구**를 검토합니다.
3. **클라우드에 보낼 정확한 문구 미리보기**를 Enter로 엽니다. **전송할 낭독 문구**에서 `Before: Button`, `After: Change delivery address, Button`을 먼저 읽고, 그 아래 **함께 전송할 지시문**을 확인합니다. 개인정보가 없고 전송에 동의한다면 **개인정보가 없음을 확인했고, 위 문구 그대로 Gemini 클라우드에 보내는 데 동의합니다.**를 Space로 체크합니다. **이 문구를 승인했습니다. 전송 버튼을 눌러야 요청이 시작됩니다.** 상태를 확인합니다.
4. **승인한 문구를 Gemini에 전송 (새 탭)**을 Enter로 누릅니다. **Gemini 전송 탭**은 열릴 때 작업 공간의 언어를 따릅니다. 탭을 열어 두고 **Gemini 응답을 기다리는 중입니다…**(처리 중), **클라우드 카드를 받았습니다. 작업 탭으로 돌아가세요.**(성공) 또는 **클라우드 카드가 만들어지지 않았습니다. 작업 탭으로 돌아가세요.**(실패) 상태를 확인합니다.
5. **전송 탭 닫기**로 작업 공간에 돌아옵니다. 성공했다면 **Gemini가 작성한 이중 언어 이슈 카드**의 두 언어 섹션에 승인한 영어 인용이 미리보기와 똑같이 남아 있는지 확인합니다.

**한국어 대안:** **합성 샘플 불러오기**로 한국어 예시를 열 수 있습니다. 모델 없이 패턴 가림과 직접 편집을 사용한 뒤 같은 방식으로 미리보기와 승인을 확인합니다.
