# 다시듣기 v2 심사 체크리스트

[공개 작업 공간](https://replay-a11y-hybrid-2026.web.app/)을 데스크톱 Chrome에서 스크린리더와 함께 엽니다. 심사는 실제 영상과 같은 **내장 영어 배송지 변경 샘플**로 시작합니다. 클라우드 카드에 기기 내 모델이나 로컬 카드가 필수는 아닙니다.

**낭독 확인 기준:** 굵은 글씨는 UI 레이블·상태 문구입니다. 핵심 의미를 들을 수 있는지 확인하되, 낭독 순서나 토씨까지 일치할 필요는 없습니다. 아래는 기대 동작이며, 실제 스크린리더 발화를 확인한 결과가 아닙니다. 모바일 TalkBack 녹음은 아직 없습니다.

1. Tab으로 **영어 합성 샘플 불러오기**에 이동해 Enter를 누릅니다. 초점이 옮겨진 **2. 수정 전후 비교** 제목과 패턴 가림으로 초안을 만들었다는 상태를 확인합니다. 영어 비교는 `Button` → `Change delivery address, Button`입니다.
2. **카드에 들어갈 정확한 문구**를 검토합니다. 기기 내 모델을 쓸 수 있다면 **기기 내 모델 제안 받기**로 가상 이름을 가리는 제안을 확인하고 **추가 가림 제안 적용**을 누릅니다. 모델을 쓸 수 없으면 이 단계만 건너뛰고 필요하면 직접 편집합니다. 같은 초안에서 **클라우드에 보낼 정확한 문구 미리보기**를 Enter로 열어 **Gemini로 보낼 전체 텍스트 (최대 1,000자)** 제목, 지시문, `Before: Button`과 `After: Change delivery address, Button`을 확인합니다.
3. 미리보기에 개인정보가 없고 전송에 동의한다면 **개인정보가 없음을 확인했고, 위 문구 그대로 Gemini 클라우드에 보내는 데 동의합니다.**를 Space로 체크합니다. 승인 상태와 전송 버튼을 따로 눌러야 한다는 안내를 확인합니다. 체크만으로는 전송되지 않습니다.
4. **승인한 문구를 Gemini에 전송 (새 탭)**을 Enter로 누르고 **Gemini relay** 탭을 열어 둡니다. 요청이 성공하면 **Cloud card received. Return to the workspace.** 상태를 확인합니다.
5. **Close relay tab**으로 작업 공간에 돌아와 제목 탐색으로 **Gemini가 작성한 이중 언어 이슈 카드**를 찾습니다. **English**, **한국어** 두 섹션에 승인한 영어 인용이 미리보기와 똑같이 남아 있는지 확인합니다.

**한국어 대안:** **합성 샘플 불러오기**로 한국어 예시를 열 수 있습니다. 모델 없이 패턴 가림과 직접 편집을 사용한 뒤 같은 방식으로 미리보기와 승인을 확인합니다.
